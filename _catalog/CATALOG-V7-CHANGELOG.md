- Composite rows (fix1/fix2, x1/x2, y1–y3) carry no embedded prompt
  metadata (PIL / masked-inpaint products): their catalog recipe is
  inherited from the base render (r1; xbaseb; ybasea) with the method
  disclosed in `lifecycle_basis`; `derived_from` names the immediate
  parent. The registry's fix2 card uses the method-style recipe.

  fix1 were synced to primo `_candidates/` so every v7 path is literal.

  remain uncataloged, as in v6 for unruled retries.
